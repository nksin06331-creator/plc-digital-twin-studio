# PLC Digital Twin Studio

GX Works2の命令リストから**等価ラダーを表示し、仮想試験盤のスイッチでランプ・正逆転モーター・数値表示を動かす**ブラウザアプリです。教育用モデルであり、特定の技能検定年度・盤メーカー・実PLCとの完全一致を保証しません。実機への接続・制御は行いません。

## Windowsで起動

Node.js 24推奨。GitHubのmainからZIPをダウンロードして展開し、`package.json`のあるフォルダーでPowerShellを開きます。

```powershell
npm.cmd ci
npm.cmd run dev
```

表示されたURLをブラウザで開きます。終了はPowerShellでCtrl+C。更新したZIPは別フォルダーに展開してください（個人の回路ファイルを上書きしないため）。

## 最初に試す

初期表示の `exam_conveyor` は、このアプリ用に作成したコンベア実習回路です。公開過去問の解答や受領した回路ではありません。

1. **試験運転開始**を押す。
2. 手動のまま **PB2** を押し続ける → パレットが左へ移動し、左端LS2で停止。離すと途中でも停止。
3. **PB3** を押し続ける → 右へ移動し、右端LS1で停止。
4. 右端で **SS0を自動**にして **PB1** を押して離す → 1往復して右端で停止。SS1を入にすると連続往復。
5. **PB5**を押している間は非常停止入力（b接点がOFF）。DSWの数字の上下にある＋/−ボタンで設定を変更すると、数値表示が追従します（0〜9で循環）。数字を直接選択する操作も使えます。

PB1〜5はキーボードのZ/X/C/V/Bでも同時操作できます。ボタンをフォーカスしたSpace/Enterにも対応。「試験用に配置」でパレットの位置、番号0〜7、片道時間を変更できます。パレット上のネジもクリックまたはキーボードのSpace/Enterで脱着できます。上から重み4/2/1で、番号選択欄と同期します。左端では番号ビットがLS3/4/5へ自動反映されます。

**2級試験盤の機器数と位置関係**は、厚生労働省公開の2019年2級器具配置図と三菱電機エンジニアリングFA-T-P01、オムロンKENTEI-PLCの公開資料を照合して再構成しました。上部の端子台、中段のCP1・駆動リレー・コンベア、下段のランプ・スイッチ・表示器を固定配置しています。[調査資料と再現範囲](docs/exam-panel-research.md)を参照してください。現行年度・全会場や実寸の完全一致を保証するものではありません。

サイドバーの「盤モデル」で汎用盤に切り替えると、従来の `training_demo`、`basic_and`、`self_hold`、`mov_example` をX直接操作で試せます。

運転開始・再開時は0msで入力条件を評価してから時間進行を開始します。「1スキャン」は現在の入力で1回だけ演算し、その出力で100ms分の搬送を進めます。停止中に変更した非常停止入力も搬送前に評価します。

「試験運転停止」はスキャンと搬送を一時停止します。出力メモリは保持されます。「全メモリ初期化」はPLCメモリ、タイマー、パルス履歴と盤を初期化し、右端・番号7・電源ON・PB5未押下へ戻します。試験盤モデルではLS1/PB5の入力がONになります。

## 2級対策・総合演習

サイドバーの **2級対策・総合演習** で、手動の左右先押し優先、タイマー、ネジ番号の3bit読取、DSW保持、数値演算、往復計数、単発/連続運転、異常保持と安全条件付き復帰を含む回路を読み込めます。読込時に試験盤・標準割付・右端・番号7・DSW2へ初期化します。独自割付は先にJSONへ保存してください。

右端でSS0を自動にしてPB1を押して離すと、ネジ番号7・DSW2の場合、左端で **07** → 復路で積の **14** → 1往復完了後に **01** を表示します。ネジとDSWの操作は実際にこのラダーの入力として処理します。操作手順・内部デバイス・確認項目は画面と [総合演習仕様書](docs/grade2-exercise.md) にあります。

自作の対策用演習であり、実際の過去問の解答や合格保証ではありません。実機配線・工具作業・計画立案・学科なども別途練習してください。入門用の `exam_conveyor` も残しています。

## 自動運転が始まらない場合

盤の上部の「運転ガイド」で理由を確認できます。まず「試験運転開始」でPLCをRUNにし、SS0を自動に切り替え、右端に戻してからPB1を押します。総合演習ではDSW1〜9と異常なしも必要です。表示99の場合はPB5を離し、手動でPB1〜3を解放してからPB4を新しく押して復帰します。

試験盤・汎用盤の入力変更はRUN中に即座に0msの論理スキャンへ反映します。DSWの複数ビットは一括反映します。短いマウスクリックの押下・解放も捕捉し、入力イベントだけで搬送距離やタイマー時間を余分に進めません。通常の時間進行は100ms周期です。入力変化スキャンも実行回数へ含め、ログに区別して表示します。

## GX Works2 CSVを使う

ファイル選択またはドラッグ＆ドロップで読み込みます。File APIで処理し、CSVは外部へ送信しません。

### 検証した実形式

ユーザーから提供された日本語GX Works2リスト出力の一例で、読込・ラダー復元・スキャン・ブラウザでの入力→出力を確認しています。受領ファイルそのものはリポジトリやビルドへ含めていません。

- UTF-16LE BOM付き、タブ区切り、二重引用符付きのセル
- プログラム名と`PC情報:`メタデータに続く、次の7列ヘッダー
- オペランドが後続行に続く形式。継続行はステップ/命令が空欄でI/O列にオペランドが入る

| ステップ番号 | 行間ステートメント | 命令 | I/O(デバイス) | 空欄 | PIステートメント | ノート |
| ------------ | ------------------ | ---- | ------------- | ---- | ---------------- | ------ |

アダプター名は `gx-works2-list-ja-v1`。ステップ番号、命令、オペランド、コメント、元の物理行、各オペランドの継続行位置を別々に保持します。ヘッダー完全一致を要求し、未知の列数・空欄列の使用・先行命令のない継続行・ステップ重複/逆順は実行をブロックします。未知の形式はプレビューを表示して拒否します。

UTF-8/BOM、UTF-16LE/BE BOM、Shift_JIS/CP932互換デコードに対応。BOMがなければUTF-8厳密デコードを試し、不正な場合のみShift_JISを推定します。文字コードの手動指定も可能です。全GX Works2バージョン・言語・出力オプションの対応は未検証です。

### 実盤との割付

CSVはプログラムであり、実際の端子とX/Yの配線までは確定できません。

試験盤モデルでは **I/O割付・接点状態** を開き、LS/PB/SS/DSWとRY/PL/DPLを各X/Yに割り当てます。初期割付はデモ用X10〜X1F、Y30〜Y3Dの端子順連番です。ユーザーの回路と必ず同じとは限りません。割付の適用時は検証後に一括更新し、PLCメモリと盤を初期化します。割付JSONの保存/読込にも対応（読込後の適用は明示操作）。割付データをサーバーに送りません。

PB5は自動復帰b接点、LSは検出時ONのモデルです。コンベア位置とパレット番号がLS入力を生成し、Xをモニターから直接変更することはできません。CP1をOFFにすると盤の入力・負荷・電源灯がOFFになり、PLCの演算・メモリは別系統として扱います。RYの同時指令は相互インターロックとして停止・警告表示します。

汎用盤モデルでは「割付設定を表示」から各Xの接点種別、各Yの表示機器、正逆転モーター、BCD先頭を設定できます。汎用盤設定は画面内だけに保持します。

### サンプル専用形式

`samples/`の6ファイルは独立した `sample-v1` アダプター向けであり、GX Works2実出力ではありません。

```csv
step,instruction,operand,comment
0,LD,X0,入力
1,OUT,Y0,ランプ
2,END,,
```

## ラダー表示

LD/AND/OR、ANB/ORBのブロック、MPS/MRD/MPPの分岐から論理式を組み立て、各出力を1回路として描画します。**元のGX Works2の段組・座標・線の配置の復元ではなく等価回路表示**です。分岐の共通部は出力ごとに繰り返して表示します。

接点は最終スキャンのその命令位置で評価した導通/非導通を表示し、右端は出力命令の実行条件を表示します。SETコイル等の条件OFFとメモリのOFFは同じ意味ではありません。機器の現在状態は試験盤/モニターで確認してください。接点の色は電流経路全体の色ではありません。

接点・出力をクリックするとソースのステップを選択。「詳細解析」を開くと命令リストと対応します。表示は1000命令まで、CSV読込は2 MiB / 20,000レコードまで。未対応・不正プログラムはラダーを誤描画せず診断を表示します。

## 演算エンジンの対象仕様

React/DOMから分離した `src/core` が演算を担当します。100msごとの論理スキャンを使用し、実時間精度は保証しません。X/Yは16進、M/D/T/C/SMは10進アドレス。実CPUのアドレス上限は再現しません。

| 命令・機能                      | 対応範囲                                                           |
| ------------------------------- | ------------------------------------------------------------------ |
| LD / LDI / AND / ANI / OR / ORI | X/Y/M/T/CおよびSM400の接点                                         |
| ANB / ORB                       | LDブロックのAND/OR結合。スタック不足/未結合は拒否                  |
| MPS / MRD / MPP                 | 条件の保存・読出し・取出し。スタック不整合は拒否                   |
| OUT / SET / RST                 | Y/M出力。命令順に即時更新、SET/RSTは条件成立時のみ変更             |
| LDP                             | 命令位置ごとの立上り1スキャンパルス                                |
| MOV                             | D/C現在値/K/H/桁指定からD/桁指定への条件付き16bit転送              |
| K1〜K4のX/Y/M桁指定             | 4〜16bitを下位ビットから展開。入力への書込みは拒否                 |
| OUT Tn 設定値                   | **本モデルではすべて100ms単位の非保持タイマー**。条件OFFでリセット |
| OUT Cn 設定値                   | 通常16bit加算カウンター。立上りで加算、設定値で接点ON、OFF時保持   |
| RST Cn                          | 現在値と完了接点をクリア                                           |
| INCP                            | 条件の立上りでDを1増加（16bit折返し）                              |
| *                               | 符号付き16×16bit乗算、連続D2ワードに32bit結果                      |
| BCD                             | 0〜9999の整数を4桁BCDへ変換。範囲外でスキャン全体を取消            |
| LD/AND/OR + =, <>, >, >=, <, <= | 符号付き16bit比較                                                  |
| SM400                           | スキャン中常時ON                                                   |
| END                             | 必須。以降の命令は拒否                                             |
| BMOV                            | 範囲メタデータを保持。実行は未対応                                 |

同一タイマー・同一カウンターへの複数のOUTは未対応として実行前に拒否します。

タイマー単位・保持区分・分解能は実CPU/パラメーターで異なります。この100msモデルの実機一致は未検証です。Dは符号なし16bitパターンで保持し、符号付き表示を併記。Kは−32768〜65535、Hは0000〜FFFF。比較/乗算では符号付きとして読みます。D初期値はEnter/フォーカス移動で確定、Escで取消。

スキャン前に命令・オペランド・スタックを検証。不明命令をNOPにしません。実行中のBCD範囲外・負数タイマー設定等のエラーも、メモリ・タイマー・パルス履歴を部分更新せずスキャン全体を取消します。

未対応: 実盤の3D形状、慣性・電気的遅延を含む詳細物理モデル、実機通信、32bit・高速カウンター、その他特殊リレー、割込み、インデックス/間接指定、保持タイマー、CPU固有動作、任意の未登録命令。これらを含むプログラムは実行できません。特定の検定盤と同じ全機能を備えたとする主張はしていません。

## 開発・検証・公開

```sh
npm ci
npm run dev
npm run build
npm run test
npm run lint
npx playwright install --with-deps chromium
npm run test:e2e
# 既存Chromiumを使う場合
CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e
```

ホームキャッシュへ書込めない場合は `npm ci --cache /tmp/plc-npm-cache`。既存チェックアウトを使い、明示指示がない限りworktreeは作成しません。

- `src/parser`: デコード、CSV/TSV構文、GX/サンプルの独立アダプター
- `src/core`: メモリ、命令実行、検証、等価ラダー論理式（UI非依存）
- `src/analyzer`: 読書区分、ソース行、命令集計、桁指定/範囲解析、CSV出力
- `src/core/plant`: React非依存のコンベア・パレット・センサー・割付モデル
- `src/components`: ラダーモニター、資料に基づく試験盤、汎用盤、詳細解析UI
- `tests`, `e2e`: 合成fixtureによる自動テスト。受領回路を格納しない

CIはpush/PRでlint・単体テスト・build・Chromiumテストを実行します。PagesはmainのCIがすべて成功した場合に、そのCIで生成したdistだけを配置します。手動実行はActions → CI → Run workflowでmainを選びます。管理者がSettings → Pages → SourceをGitHub Actionsに設定する必要があります。

CSV・設定を外部送信せず、解析データはブラウザメモリのみで扱います。HTMLとして実行せず、外部ログ・CDN・アクセス解析を使用しません。CSV出力はセル引用と数式先頭の無効化を実施。Pagesのビルドには公開サンプルだけが入り、読込済みユーザーCSVは入りません。

解析詳細は展開時だけ描画し、命令は100件、モニター・参照・診断は50件ずつページ表示します。CSV出力には全参照を含みます。連続アクセスの終端番地が安全な整数範囲を超える場合は診断を表示して実行を拒否します。割付入力の番地表記は適用時に正規化します（例: X0010 → X10）。

ファイル選択は拡張子で絞り込まないため、テキストとして保存したリストも選択できます。対応可否は内容のヘッダーで判断し、未知の形式は実行を拒否します。ZIP内のCSVは先に展開してから選択してください。

画面上部の「現在のプログラム」はスクロール中も表示し、ファイル名、デモ回路／選択したファイルの区別、命令数、実行可否を確認できます。読込中のデモボタンも色で示します。

## Cカウンター演習

サイドバーの **カウンター演習** は自作のsample-v1回路です。試験盤の標準割付で試験運転を開始し、**PB1を2回押す**とDPLが02になりPL1が点灯します。長押しでは1回だけ加算し、PB4で00と接点OFFに戻ります。独自割付を使用中の場合は、保存したうえで標準割付を適用するか、回路に合わせて割付を設定してください。

Cは通常16bit加算モデル（設定値1〜32767）です。OUTの条件がOFF→ONの時だけ加算し、入力OFFで現在値と完了接点を保持します。完了後は加算を止め、設定値を変えてもRSTまで保持します。設定値は未完了の次の立上りで評価します。RSTとOUTは命令順に実行し、RSTだけでは保持中の入力を新しい立上りにしません。全メモリ初期化はカウンターと立上り履歴も消去します。

`LD C0`等では完了接点、`MOV C0 D0`や比較・BCDのワード読出しでは現在値を使用します。詳細モニターで両方を確認できます。CへのMOV/SETは対象外です。32bit・高速・停電保持やCPU固有のカウンター差異は再現せず、実機一致は未検証です。

## 割付の編集と適用

表の「編集する番地」は下書きで、「適用中の番地」「適用中の状態」が現在の運転に使われます。変更した行と未適用件数を表示します。**割付を適用・初期化**で全項目を検証してから一括適用し、PLCと盤を初期化します。不正・重複がある場合は適用せず、下書きと未適用表示を残します。**編集を破棄**は下書きだけを戻し、運転やPLCメモリを変えません。JSON読込も下書きとして入り、JSON出力は適用中の割付を保存します。

## ラダーを読みやすく表示する

ラダーモニターは明るい回路背景で、番地・接点記号・コイル・命令名・導通状態を表示します。回路ごとに番号、出力ステップ、コメントを添えます。初期倍率は全体を見渡す50%で、**全体表示（50%）**ボタンで戻せます。60%以下では接点のステップ等の補助表示を省略し、番地と状態を表示します。**表示倍率**は40〜200%で変更でき、**100%に戻す**で等倍に戻ります。**回路の幅を広げる**で回路側の比率を増やせます。**幅を均等に戻す**で戻ります。盤と回路は常に横並びです。長い回路は回路エリア内で縦横にスクロールでき、エリアにフォーカスして矢印キーでも操作できます。表示操作はPLC演算やメモリを変更しません。

## メニューと作業画面

左端の細いメニュー帯にカーソルを合わせると、ファイル読込・デモ・盤モデルなどのメニューが重なって開きます。マウスがない場合は**メニューを開く**ボタンを押してください。外へ移動するか、閉じるボタン／Escapeで閉じられます（メニュー内にフォーカスがある間は表示を保持します）。メニューの開閉で盤と回路の位置は変わりません。CSVは閉じたメニュー帯へ直接ドラッグ＆ドロップできます。

盤と回路は画面幅によらず横並びで、各枠内を独立してスクロールできます。長いファイル名で上部の表示が折り返しても、作業領域の高さを調整します。盤は枠の大きさに合わせて縮小します。**盤を100%で表示**で原寸の表示へ切り替え、枠内をスクロールして操作できます。**盤を枠に合わせる**で戻します。スキャン操作・ファイル名の表示は上部にまとめ、総合演習ガイドや詳細解析は作業画面の下から参照できます。

CSV読込後に「CSVと盤の割付を確認してください」と出た場合、CSVのX/Y番地が盤へ未接続です。X0〜XF・Y20〜Y2Dの連番構成は「X0/Y20割付を適用・初期化」で切替できます。LS・PB・SS等の機器の意味はCSVだけでは確定できないため、表示する対応表と実際の割付表を照合してください。自動適用やCSV番地の書換えは行いません。
