# Validation

ローカル確認環境: Node.js 24.22.1 / npm 11.9.0 / Chromium。

- `npm run build`: TypeScript検証・Vite production bundle成功
- `npm run test`: Vitest 75件成功
- `npm run lint`: ESLint成功
- `CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e`: ブラウザ27件成功

単体テストは、CSV/TSV、UTF-8/CP932/UTF-16、継続行とソース位置、空/巨大/不正入力、基本接点・保持、スキャン順、16bit、OR/ANDブロックの全入力組合せ、MPS/MRD/MPP、パルス、タイマー、桁指定、BCD、符号付き比較/乗算、実行エラー時の状態取消を確認しています。追加の10件でコンベアの移動/端部停止、全パレット番号のLS生成、盤電源、相互インターロック、BCD、割付検証、手動/自動/連続運転をPLCと閉ループで検証しています。GX形式のリポジトリfixtureは合成データです。

ブラウザは、押しボタン・保持・NC接点、ランプ、自己保持、正逆転、同時ON異常、BCD設定器と数値表示、ラダー、詳細解析、CSV出力、未認識CSV、HTML非実行、D値編集、ウィンドウ非アクティブ時の押しボタン解放、巨大アドレスの拒否、390px幅の表示を確認しています。固定試験盤では、器具数、実際のパレット移動とLSフィードバック、自動1往復、非常停止、割付の適用/JSON入出力、不正割付を適用しないこと、同時指令時の停止も確認しています。自動往復の一瞬だけONになるLS2はPlaywrightの仮想時計で100ms単位の状態を確認します。

受領した実GX Works2ファイルをリポジトリ外のローカルファイルとして別途検証しました。UTF-16LEの123命令を診断エラーなしで読み、36出力回路に復元し、100スキャンを完了。ブラウザでもCSV読込→入力操作→出力ランプ→割付モーターの正転表示を確認しました。新しい固定試験盤でも、試験用割付を明示指定してCSV読込→PB2入力→パレット移動をブラウザで確認しました。回路の内容やそのファイルをリポジトリ・CI・公開ビルドへコピーしていません。

未検証: 実PLCとの波形/スキャン比較、全GX Works2出力オプション、特定検定盤との機器/配線一致、実CPUのタイマー単位、GitHub-hosted Actionsの結果、Pagesへの公開結果。100msタイマーモデルと資料に基づく教育用搬送モデルの検証結果であり、実機一致の証明ではありません。

## 総合演習の追加検証

18件の単体テストで、全有効パレット番号1〜7の番号/積表示と1回計数、DSWの往復中保持、PB1長押しを番号ビットへ混入させないこと、最大積63、回数99→00、連続運転の次周期でのDSW再取込、左右先押し優先と反転前1スキャン停止、右端以外の始動拒否、非常停止と手動切替での異常保持、PL4点滅、DSW0/番号0の拒否、新しいPB4立上りが必要な復帰を確認。

ブラウザの総合演習2件で、標準割付と盤の切替、DSW初期値2、07→14→01の表示、非常停止99と手動PB4復帰、モバイル表示を確認。ネジ個別脱着とDSW上下操作の既存の追加2件も含めて全20件を実行しています。

## 短いクリックと自動始動ガイドの回帰検証

0msの入力変化スキャンで立上りを捕捉し、タイマー時間を加算しないことを単体テストで確認。ブラウザの時計を止めたままPB1を通常クリックして自動要求が保持され、時間を進めると搬送すること、短いPB5で異常が保持され、手動の短いPB4で復帰できることを検証しました。停止・手動・DSW0・右端不在・PB1を押したまま自動に切り替えた状態について、画面のガイドが理由を示すことも確認しています。

## 全体レビュー後の回帰検証

停止中の非常停止入力を保持した再開で位置が変わらないこと、汎用盤の短いクリック、BCDダイヤルの原子的な更新、割付番地の正規化、異常番地の診断と画面復帰、ページ送りと参照先への移動をブラウザで検証しました。単体テストでは重複タイマーOUTの事前拒否、別タイマーの独立計時、最大行数の参照保持、全件CSV出力も検証しました。
