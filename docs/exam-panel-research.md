# 2級試験盤の調査と実装範囲

確認日: 2026-11-14（日本時間）。現行年度の全会場に共通する盤を特定したという意味ではありません。以下の公開済み資料で、過去の実技試験盤と対策機材の共通構成を確認しました。

## 一次資料

1. [厚生労働省公開：2019年1月度 2級 電気機器組立て（シーケンス制御作業）試験問題概要](https://sespp.mhlw.go.jp/2025/vietnam/public_ja/SequenceSkillLevel2_ja.pdf)
   - 資料p.5: 試験場で準備する機材の数量。
   - 資料p.6: 器具配置図。上部TB、CP1とRY1/RY2、中央コンベア、左側LS2〜LS5・右側LS1、下部電源灯・PL1〜4、SS0/SS1・PB1〜5・DPL2/DPL1。
   - 資料p.7: 端子1〜16、20〜33、RYの相互インターロック、PB5の接点、PLCとの接続。
   - この公開例は2019年の問題で、掲載先パスの2025は問題の年度ではありません。
2. [三菱電機エンジニアリング：国家技能検定試験対策ユニット FA-T-P01](https://www.mee.co.jp/sales/fa/meefan/system_maintenance/training.html)
   - 「実技試験機材に使用されている製品」と明記。
   - 「器具配置図」「入出力配線図」でDSW、LS3〜LS5の重み2⁰/2¹/2²、端子の機能を確認。
3. [オムロンFAストア：KENTEI-PLC](https://store.fa.omron.co.jp/associates/skill/exam/sequence.html)
   - 実技試験会場と同等品の対策用作業盤。外観写真と搭載商品リストで構成を照合。
   - [メーカー公開カタログ OFS-005N](https://store.fa.omron.co.jp/associates/skill/pdf/OFS-005N_KENTEIPLC.pdf)も照合。

調査のため取得したPDF・写真・図版はリポジトリへ収録していません。画面は機器の機能と位置関係を基に独自のHTML/CSSで描画しています。メーカーのロゴや写真の貼り付けではありません。

## PLC割付と動作モデル

盤の端子番号とPLCのX/Y番号は異なります。初期割付は公開デモ用として入力X10〜X1F、出力Y30〜Y3Dを端子順に割り当てたもので、実会場共通の割付ではありません。CSVだけから配線を断定しません。利用者は割付表を編集し、JSONで入出力できます。適用は全項目の検証後に一括実施し、メモリと盤を初期化します。アドレスの重複（表記違いも含む）や型違いは拒否します。

スキャン間の100msに前回のPLC出力でパレットを移動し、その位置でLSとスイッチ入力を採取して次のPLCスキャンを行います。描画タイミングからPLCの条件演算は行いません。単発スキャンも同じ100msの論理時間で進みます。

初期位置は右端、番号は7、PB5は未押下で接点ONです。全初期化ではこの物理初期状態へ戻ります。したがって試験盤モデルのXは全ゼロにはならず、LS1とPB5がONです。汎用盤モデルは従来どおりXを直接操作できます。

速度は片道1/4/8秒から選ぶ教育用設定。位置は端部でクランプし、0.1%以内を端部へスナップします。慣性、負荷、電気的遅延、故障、機械的寸法・色の完全再現は対象外です。RY同時指令時の実機の先着動作は再現せず停止します。コンセントは外形表示のみです。最新年度・メーカー固有の仕様一致を主張しません。

## デモ回路

`samples/exam_conveyor.csv` はこのアプリ用に作成した回路で、過去問の解答や受領したユーザープログラムではありません。手動の左行/右行、端部停止、自動1往復、連続往復、非常停止入力、表示灯とDSWのBCD表示を試せます。シーケンスの仕様は実技試験の各年度課題そのものとは異なります。
