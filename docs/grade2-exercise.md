# 2級対策・総合演習

対象: `samples/grade2_comprehensive.csv`（sample-v1形式、219命令）。このアプリ向けに作成した練習回路です。実際の過去問・模範解答の転載ではありません。技能検定2級の合格を保証せず、実機配線・工具作業・計画立案・学科・試験当日の仕様理解などは別途練習が必要です。

## 起動

サイドバーの **2級対策・総合演習** を選びます。試験盤モデル・標準割付・右端・番号7・DSW2へ初期化し、試験運転は停止状態で読み込みます。自分の割付を残す場合は先にJSONで出力してください。**試験運転開始**で動作を開始します。

既存の `exam_conveyor` は入門用として残しています。総合演習の仕様は入門用と異なります。

## 仕様を読んで確認する

| 操作・条件                         | 期待する動作                                                                                                |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| 手動PB2 / PB3                      | 押している間の左行 / 右行。LS2 / LS1で停止                                                                  |
| 左右を順に同時押し                 | 先に押された方向を保持。先ボタン解放後、1スキャンの無出力期間を挟んで後方向へ。同一スキャンでの押下は左優先 |
| 手動から自動へ                     | 搬送要求を解除。右端待機から新しいPB1立上りで始動                                                           |
| 自動PB1                            | 右端・PB5解除・異常なし・PB2/3解放・DSW1〜9で左行開始                                                       |
| 自動の左端到達                     | LS3〜LS5の3ビットから番号を保持。番号0は異常                                                                |
| 左端待機                           | 保持DSW×10をT0の設定値にする。100msモデル上でDSW秒を積算                                                    |
| 復路                               | 保持したネジ番号×保持DSWを表示し、右行。端部で停止                                                          |
| 右端完了                           | D20を1回だけ増加。99の次は00                                                                                |
| SS1が入                            | 完了した右端から次の往復を開始。DSWを取り直す                                                               |
| SS1を切に変更                      | その往復を最後まで行い、右端で停止                                                                          |
| 非常停止PB5 / 自動運転中の手動切替 | 異常を保持、運転工程を解除、両出力OFF                                                                       |
| DSW0で自動始動 / 連続の次往復開始  | 異常保持。往復途中にDSWを0へ変えても、その往復は開始時の値で完了                                            |
| 異常中                             | DPLに99、PL4が約0.5秒ごとに点滅。PB5を離すだけでは復帰しない                                                |
| 手動PB4の新しい立上り              | PB5が解除、PB1〜3が解放、LS矛盾なしの場合に異常・工程・完了回数を初期化                                     |

片道速度は盤の試験設定です。PLCのスキャン周期、タイマーの単位・精度・初回積算の振る舞いは本アプリの100msモデルに従います。実機の時間精度・型式差の検証を置き換えるものではありません。

PB4を先に押したままPB5を解除しても復帰しません。一度PB4を離してから押し直してください。途中で異常停止した場合は、復帰後に手動で右端へ戻し、自動へ切り替えてPB1を押します。盤電源OFFでもPB5入力はOFFになるため、再給電後に復帰操作が必要です。

## DPL1/2の表示の優先順位

DPL1は1位、DPL2は10位です。表示は常にラダーの `BCD D40 K2Y36` から出力し、画面側でLSやDSWから直接数値を書き換えていません。

1. 異常中: **99**（最優先）
2. 手動でPB1を押している間: **完了回数**
3. 自動復路: **番号×往復開始時DSW**
4. 左端待機: **取り込んだ番号**
5. 自動の待機・往路: **完了回数**
6. 手動の通常表示: **DSW現在値**

番号7・DSW2の1往復なら、左端で **07** → 復路で **14** → 右端で **01** を確認できます。ネジ番号は左端到達時に保持されます。取り込んだ後にネジを変えてもその往復の表示は変わらず、次の左端到達時に取り直します。DSWも往復開始時の値を保持するため、途中の変更は待ち時間・積に影響しません。

表示99は完了回数99と異常の両方で使います。PL4の点滅と正常モード灯が消えていることを併せて確認します。

## 学習用デバイス表

標準I/O割付は `docs/exam-panel-research.md` と画面の割付表を参照してください。以下はこのデモ専用の内部デバイスです。

| デバイス        | 意味                                                        |
| --------------- | ----------------------------------------------------------- |
| M9              | 前スキャンまでの自動運転中判定                              |
| M10 / M11 / M12 | 左行 / 左端待機 / 右行工程                                  |
| M30 / M31       | 手動の左 / 右要求                                           |
| M32 / M33       | 前スキャンの手動要求の写し。左右の1スキャン無出力期間を作る |
| M100 / M101     | PB1 / PB4の立上りパルス                                     |
| M102 / M104     | 左端 / 右端到達イベント                                     |
| M105〜M108      | 連続再始動、復帰許可、始動受付、往復開始イベント            |
| M900            | 異常保持                                                    |
| M908            | 両端LSの矛盾                                                |
| D0              | 往復開始時のDSW                                             |
| D1 / D2         | 待ちタイマー設定値DSW×10と乗算上位ワード                    |
| D10             | 取り込んだネジ番号                                          |
| D12 / D13       | 番号×DSWと乗算上位ワード                                    |
| D20             | 完了回数00〜99。INCPで計数し比較で折返し（C命令ではない）   |
| D30             | 毎スキャンのDSW現在値                                       |
| D40             | 最終表示値。最後にBCD変換して出力                           |
| T0              | 左端待ち時間                                                |
| T1 / T2         | 異常点滅用のタイマー                                        |

番号読取りで `MOV K1X12 D10` を使っていない理由も確認してください。LS3〜LS5はX12〜X14の3点ですが、K1は4ビットなのでPB1のX15まで混入します。このデモは3接点の組合せから0〜7へ変換し、PB1を押し続けても番号を誤読しません。

MPS/MRD/MPPで開始条件を共有し、SET/RSTで工程を保持します。書込みが複数あるデバイスには解析の参考警告が出ますが、意図した工程遷移と異常時解除です。各書込みの順序をクロスリファレンスで追ってください。

## 自分で確認する演習

- ネジ番号1〜7をすべて試し、左端の表示とLS3/4/5を照合する。全外し0は異常になることを確認。
- DSWを1・2・9に変え、待ち時間と復路の積を照合する。途中で変更しても保持値が変わらないことを確認。
- 右端以外からPB1を押しても自動が始まらないことを確認。
- 左右それぞれを先に押し、同時押しと解放時のインターロックを確認。
- 連続運転で完了回数が1往復につき1回だけ増えることを確認。手動でPB1を押して回数を確認。
- PB5を押して離すだけでは復帰しないこと、PB4先押しでは復帰しないこと、正しい復帰条件を確認。
- 表示99を見ただけで異常と決めず、PL4とモード灯から判断する。

発展課題: 3往復で停止、終了時に一定時間ランプを点灯、異常の種類ごとに別の表示コードを付ける、などを自分の回路で実装して仕様・テストを作ってください。本アプリが未対応の命令を使う場合は実行がブロックされます。
